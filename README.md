# SUCCEED Digital

1. Purpose: An interactive aid for completing the 33-item SUCCEED reporting checklist
2. Access: A link to the published app. JavaScript must be enabled. No installation, account, or internet connection is needed for checklist work.
3. Use: Select a status for each item you review. Record manuscript locations and notes as needed. A whole-item “Not applicable” selection needs a justification before it counts as a recorded response and before document export. Use Notes for exceptions affecting only part of an item.
4. Saving: Changes are autosaved in the same browser profile and location. For offline file URLs, storage behavior varies by browser. The toolbar shows when autosave is unavailable. Responses are saved in the same browser on the same device. Clearing browser data may erase them.
5. Explanations: Select **Explanation** beside an item to expand its explanation from the supplied document. Select **Hide explanation** to close it. Each panel cites the source page and links to the bundled PDF, including its examples and bibliography.
6. Download: Both download buttons become available when all 33 responses are recorded. Reported, Partial and Not reported each count as recorded. Not applicable requires a nonblank justification. Use **Download Word** for an editable DOCX or **Download PDF** for a PDF. Both include page numbers, all six sections, all 33 items, your responses, and the citation, regardless of the active filter.
7. Support: For technical problems or feedback, contact succeedguideline@gmail.com. Include a brief description of the issue and your browser name. Please do not send confidential manuscript content or personal information.
